# GameJam26Garlic

A 2D Unity game built for a game jam, blending a dating-sim dialog system with a wave-based arcade fight scene. Players navigate conversations where answers affect a satisfaction meter, then defend against enemy waves that scale in difficulty over time through a tiered spawn system.

Features mouse-follow movement with acceleration, drift, and boost mechanics, plus a ScriptableObject-driven configuration system for fast designer iteration without touching scenes. Built within a time-boxed game jam using Unity, C#, and TextMesh Pro.
